# English Quest Movers

Website học tiếng Anh dành cho học sinh lớp 3 và người học có trình độ tương đương Cambridge A1 Movers.

## Tài liệu sản phẩm

- [Product SPEC 1.0](docs/SPEC.md)
- [Product SPEC 1.0 - bản Word](docs/SPEC_English_Quest_Movers_v1.0.docx)

## Quyết định nền tảng

- Phát triển nội dung theo thứ tự Unit 1 đến Unit 12.
- Audio sử dụng giọng Anh-Mỹ.
- Tiến trình được đồng bộ nhiều thiết bị qua tài khoản phụ huynh.
- Tên sản phẩm: English Quest Movers.

Hiện repository mới chứa tài liệu SPEC; mã nguồn website sẽ được phát triển theo backlog trong SPEC.
